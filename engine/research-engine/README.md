# Research Engine

## 目标
建立足够可靠的事实底座，让创意可以大胆，事实仍然克制。

## 来源优先级
1. 官方原件 / 原始论文 / 法规 / 档案 / 财报 / 原始采访
2. 高质量专业媒体与权威二手资料
3. 专家解释与教科书
4. 社区讨论仅用于发现问题和体验，不单独支撑关键事实

## 四层标签
- **F Fact**：可核验
- **I Interpretation**：解释
- **H Hypothesis**：假设
- **R Fictional Rule**：作品规则

## 研究输出
- source ledger
- key facts
- competing explanations
- uncertainty
- dates / scope / population
- claims that must not be strengthened
- facts useful for visualization

研究不是为了堆资料，而是为了修正 Mechanism Map。
