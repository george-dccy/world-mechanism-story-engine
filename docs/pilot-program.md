# Pilot Program — Prove the Engine, Not One Film

## Why this exists

The project can fail in two opposite ways:

1. ideas are shallow but production is fast;
2. one idea becomes excellent, but the system never proves it can produce repeatedly.

The pilot program exists to avoid the second failure.

For the first three films, the primary question is:

> Can the World Mechanism Story Engine repeatedly turn different kinds of deep content into coherent 1–2 minute videos through a resumable Codex-first production workflow?

## Pilot 1 — F01

**Case:** the world's simultaneous lives vs one person's serial experience.

**Primary production challenge:**
- embodied first-person experience;
- time freeze;
- many-world window multiplication;
- context dive;
- knowing vs experiencing;
- return to one temporal line.

**Production target:** 90–110 seconds.

**What it validates:**
- Content Master → experiential video compilation;
- unified illustration Style Bible;
- Codex/art-motion + bounded H3 Lite dynamic assets;
- complex cognitive movement without lecture-style voice-over.

**Stop rule:** once first rough cut is coherent enough to review, make only high-value fixes, record system lessons, then move on.

## Pilot 2 — S01

**Case:** what happens if personalized recommendation disappears?

**Primary production challenge:**
- systems thinking;
- interfaces and allocation mechanisms;
- animated information;
- changing rules rather than changing protagonists.

**What it validates:**
- art-motion explainer grammars;
- UI / kinetic / diagrammatic motion without becoming a generic explainer;
- Wish Fulfillment Stress Test in a non-story film;
- reuse of Production Manifest and Codex continuation.

## Pilot 3 — A08

**Case:** sound remains at the physical place where it was spoken.

**Primary production challenge:**
- external task / story progression;
- characters and relationships;
- spatial sound as mechanism;
- a fictional rule that remains emotionally concrete.

**What it validates:**
- story-film production;
- character continuity;
- sound-led world building;
- whether the engine works outside essay/explainer structures.

## Why these three

Together they test three materially different forms:

| Pilot | Dominant form | Hardest production problem |
| --- | --- | --- |
| F01 | first-person cognitive experience | temporal continuity + many worlds |
| S01 | system explainer / interactive logic | allocation mechanisms + information motion |
| A08 | story / fable-like film | character continuity + spatial sound |

If only F01 works, we have made one film.

If F01, S01 and A08 all work through the same engine contracts, we have evidence of a system.

## Anti-overpolish rule

For the first three pilots:

> From approved Video Concept / Production Lock to first rough cut, allow at most one structural revision per film.

A structural revision must be supported by an observed production failure. Taste-driven polishing does not qualify.

Before first rough cut, prefer fixing in this order:

1. shot/blocking;
2. duration;
3. edit rhythm;
4. sound;
5. asset choice;
6. motion grammar;
7. only then upstream structure.

## What to measure

Do not judge pilots only by views or aesthetic polish.

Track:
- time from production initialization to first rough cut;
- number of human interventions needed to resume Codex;
- number of structural revisions;
- renderer capabilities reused vs one-off code;
- percentage of shots that survive from prototype to rough cut;
- whether viewers can state the cognitive turn without being told the thesis;
- whether the final film feels like this project rather than a generic AI video;
- what each pilot adds back into reusable skills, schemas or renderers.

## System success criterion

The pilot program succeeds when:

1. three different content forms reach watchable rough cuts;
2. each can resume from repository state without relying on old chat context;
3. each contributes reusable production capability rather than only case-specific hacks;
4. the authorial principle survives production:

> Let the audience experience the mechanism instead of hearing the author announce it.
