# Authorial Voice — 这个项目怎样“像作者在想”

## 来源

S01《首页十把椅子》第一版获得明确人工正反馈：

- 符合作者气质；
- 有惊艳感；
- 让人愿意跟着思路读下去。

因此把这次成功拆成可复用原则，但不把具体句式模板化。

## 核心不是“文风”，而是思维体验

这个项目最适合的写法不是：

> 先宣布观点 → 罗列论据 → 总结意义。

而是：

> **给读者一个具体问题 → 改一个条件 → 看旧答案失效 → 换一个答案 → 再发现新代价 → 逐步升级问题。**

读者应该感觉：
> “我刚才也是这么想的……等等，好像还有一层。”

这就是“跟着思路读下去”。

## S01 为什么有效

### 1. 先给一个可操作的局面
“首页只有十把椅子。”

不是先讲“注意力稀缺”“推荐系统中介权力”。

### 2. 每一节都让旧答案短暂成立
- 按时间；
- 只看关注；
- 自己搜索；
- 人工编辑；
- 热门榜。

每个答案都不是稻草人。

### 3. 再让它自然暴露代价
不是作者反驳读者，而是规则自己产生后果。

### 4. 结论升级问题，而不是结束问题
从：
> 推荐算法好不好？

变成：
> 谁替我筛？按什么目标？我能不能知道、切换和控制？

## 写作基准

### Concrete before abstract
先让读者看到椅子、钟、声音、路线、按钮、名单，再出现机制术语。

### Genuine alternatives
每个候选答案都要有合理性，不能为了衬托结论而故意写弱。

### State change per section
每一节至少改变一件事：
- 一个直觉；
- 一个定义；
- 一个因果关系；
- 一个利益分配；
- 一个问题本身。

如果一节只是换例子重复观点，删掉。

### No early verdict
开头不要提前说：
“真正的问题其实是……”

除非读者已经通过前面的经历自己快要走到这里。

### Intellectual but conversational
可以使用：
- “先别急”
- “再想一步”
- “那换一个”
- “问题来了”

但这些只是自然对话动作，不是固定口头禅。

### Open ending
结尾更适合：
- 一个升级后的问题；
- 一个重新看待日常物件的视角；
- 一个仍需自己判断的取舍。

不适合：
- “所以我们应该……”
- “这个故事告诉我们……”
- “科技是一把双刃剑……”

## 中国语境

默认先寻找中国读者不需要翻译背景就能理解的对象、制度和历史。

但“中国视角”不能破坏这种推理体验。

中国案例不是装饰，而应让问题：
- 更近；
- 更深；
- 更意外；
- 更有历史纵深。

## Anti-template

不要把 S01 复制成：
> 每篇都做五轮选择。

真正要保留的是：
> **让读者亲自经历机制，而不是听作者宣布机制。**
