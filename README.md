# 世界机制故事引擎 · World Mechanism Story Engine

> 借助模型加深人的思考与对世界的理解，再把这种理解编译成孩子和朋友愿意看、愿意读、愿意继续想的作品。

这个项目不是“一句话生成视频”的流水线。人的问题意识、文化位置、判断与设计在上；模型的研究、推演、写作和生产能力在下。

## 默认文化视角

> **China-first, World-second｜中国视角为主，世界视角为辅。**

先检查中国历史、现实生活、科技制度和家庭经验中是否存在更自然、更有纵深的机制入口。世界材料用于对照、校准、扩展和补证。

这不是强行中国化。详见 docs/cultural-lens.md。

## 核心链路

问题 / 母题  
→ 必要时 Research Pass A  
→ Mechanism Explorer ↔ Creative Exploration  
→ Editorial Gate  
→ Creative Blueprint  
→ Research Pass B / Evidence Pack  
→ Content Master  
→ Expression Router  
→ Video / Article / Comic / Talk / Other  
→ Production + QA  
→ Retrospective

**先理解，再表达；先设计，再生产。**

## 当前核心 Skills

### wm-mechanism-explorer
把奇怪、困惑或母题推进成机制模型。

### wm-research-agent
Pass A 创意前纠错；Pass B Blueprint 后建证据包。

### wm-creative-director
把机制变成真正值得表达的方向。重点防止：
- 第一联想锁死；
- 正确但普通；
- 美国案例默认化；
- 历史题自动历史剧化；
- 所有题被强迫故事化。

## Authorial Voice

S01 人工反馈确认了一种重要写作方式：

> **让读者经历机制，而不是听作者宣布机制。**

通过一个合理答案 → 新代价 → 换规则 → 再升级问题，让读者跟着思路往下走。

详见 docs/authorial-voice.md。

## Creative Blueprint

所有表达形式共享的“源代码”。Renderer 可以改变节奏、画面和版式，不能重新发明核心问题和机制。

## Golden Cases

### A08｜声音只能留在说话的地方
科学 / 寓言 / 关系故事。

### S01｜首页只有十把椅子
当代社会 / 思辨解释。2026-10-01 经人工反馈升级为 Golden Case。

### H01｜北京时间为什么在西安产生？
中国历史 / 科学 / 技术 / 制度。当前仍为 Golden Candidate。

## 仓库分工

- docs/：哲学、文化视角、作者气质、工作流与实跑复盘
- engine/：机制、Blueprint、故事、研究、质量
- skills/：可执行认知与创作单元
- schemas/：Blueprint / Evidence Pack 接口
- examples/：样例
- runs/：真实运行记录
- content-masters/：跨媒介内容母版
- drafts/：具体媒介试写
- renderers/：表达编译器
- tests/golden-cases/：防退化案例

## 不变边界

1. 科学是来源域，不是项目边界。
2. 热点只是入口，机制才是主角。
3. 第一联想只当 baseline，不自动成为主创意。
4. 中国视角不是地名换皮。
5. 固定爆款模板不是默认叙事结构。
6. Renderer 不能反向决定题材和思想。
7. AI 可以提出候选，但关键取舍保留给人。
8. F / I / H / R 必须分层。
9. CI 只能证明接口没坏，不能证明创意已批准。
