# Skills Roadmap

v0.1 暂不追求一个总 Skill 自动跑完。

优先把稳定的人机协作单元做成小 Skill：

1. `wm-mechanism-explorer`
2. `wm-research-agent`
3. `wm-creative-director`
4. `wm-story-builder`
5. `wm-expression-router`
6. `wm-reviewer`

原则：
- 每个 Skill 有明确输入输出；
- 关键 Gate 不隐式通过；
- Skill 可替换，schema 和 Golden Cases 尽量稳定；
- 先让方法变好，再让流程变快。
