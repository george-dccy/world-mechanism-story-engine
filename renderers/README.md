# Renderers

Renderer 是“表达编译器”，不是选题引擎。

## v0.1 候选
- story-film
- minimal-line / stickman
- whiteboard
- archive-collage
- documentary / evidence-mg
- article
- comic
- talk
- hybrid

## Renderer Contract
输入：
- 已确认 Blueprint
- 已确认 Content Master
- factual constraints
- must_preserve
- target audience
- target medium

输出：
- director / layout proposal
- medium-specific structure
- asset plan
- production package
- QA checklist

## 重要边界
- Renderer 可以改变节奏、镜头、版式、措辞长度。
- Renderer 不得改变核心问题、机制、世界规则和已确认事实。
- “当前模型擅长什么”只能影响表达策略，不能反向改写内容。

未来会吸收 stickman-video-director 的 Director Proposal / clip contract，以及 Simon Skills 的素材覆盖、时间预算、来源台账与 QA 思想。
