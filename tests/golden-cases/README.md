# Golden Cases

Golden Cases 用来保护“系统越来越自动，但作品不能越来越像流水线”。

## 当前基线

### A08｜声音只能留在说话的地方
**Golden Case**  
科学 / 寓言 / 关系故事

保护：
- 母题先行；
- 科学事实与寓言规则分层；
- 重复动作改义；
- 儿童与成人双层阅读。

### S01｜首页只有十把椅子
**Golden Case｜2026-10-01 人工认可**  
当代社会 / 技术 / 思辨解释

保护：
- 非故事型内容也可以成为核心作品；
- 让读者经历机制，而不是先听结论；
- 多方激励和替代机制；
- 非二元价值判断；
- 符合作者“跟着思路读下去”的写作气质。

### H01｜北京时间为什么在西安产生？
**Golden Candidate**  
中国历史 / 科学 / 技术 / 制度

正在测试：
- China-first, World-second；
- Truth Surprise；
- 第一联想淘汰；
- 历史题不必历史剧化；
- 公共基础设施视角。

## Golden Candidate → Golden Case

必须同时有：
1. 真正跑过完整链路；
2. 至少一份接近真实发布形态的产物；
3. 作者明确人工反馈；
4. 已能说清“哪些规律应该固化，哪些只是案例特例”。

模型不能自行把自己的候选升级成 Golden Case。
