# Golden Candidate H01 — 一张车票上的 14:37

**类型**：历史 / 技术 / 制度 / 现代反事实解释  
**状态**：Golden Candidate，v0.3，尚未人工锁定  
**主要测试**：历史机制能否用现代体验进入，而不被历史外壳拖远

## Core Question

> **为什么一张车票上的 14:37，可以同时成为乘客、司机、车站、接站家人和系统都认的“同一个未来时刻”？**

## Core Mechanism

> **标准时间真正标准化的不是太阳，而是陌生人对“未来什么时候发生什么”的共同预期。**

## Why v0.2 Failed

v0.2 曾选择“1883 年电报送信少年 + 两个正午”。

用户否定这一方向，原因：
- 电报和送信少年距离今天太远；
- 孩子需要先理解旧职业，才能进入核心机制；
- 成人也缺少现代代入感。

这个失败必须保留为回归经验：

> **历史事实可以是真实的，但表达入口仍可能是错误的。**

## v0.3 Creative Strategy

### Modern experience first
从现代车票、接站、日历邀请等人人默认的“未来坐标”切入。

### Counterfactual second
假设明天每座城市重新按本地太阳时间生活。

观察：
- 跨城车票必须标时间基准；
- 接站需要换算；
- 远程会议 / 直播 / 物流 ETA 需要额外协调；
- “下午三点见”不再自动跨城市成立。

### History last
最后才回到 19 世纪北美：
- 1883 年以前大量城镇采用地方太阳时间；
- 铁路网络一度并行多套时间；
- 1883-11-18 Standard Railway Time 切换；
- 部分地方经历两个正午；
- 1918 年才出现美国联邦 Standard Time Act。

历史成为“为什么今天这个默认存在”的解释，而不是观看门槛。

## Must Preserve

- “共享未来坐标”是核心，不退化成时区知识；
- 不把真太阳时与时区混为一谈；
- 现代体验先行，历史解释后置；
- 1883 与 1918 分层；
- 不把过去写成愚昧；
- 不把统一标准写成没有代价的单向进步；
- 不因为历史题就强迫使用历史人物做主角。

## Regression Questions

1. Mechanism Explorer 是否仍能找到“未来坐标”而不是只说铁路安全？
2. Creative Director 会不会因为题材是历史就自动选择古装 / 历史人物？
3. 是否能让一个现代孩子先理解“为什么车票时间必须共享”？
4. 1883 历史是否作为证据进入，而不是前置理解负担？
5. Renderer 是否会把它退化成“时区是怎么发明的”知识视频？
